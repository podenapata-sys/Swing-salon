# Swing Salon Dhanmondi — Website Preview

Single-page, mobile-first website preview for Swing Salon (hair, skin & nails, Road 6/A, Dhanmondi, Dhaka).

- English / Bangla toggle (add `?lang=bn` to the URL to open in Bangla)
- Hair-colour shade finder that previews six shades
- Appointment booking (services, date, time, shade) that sends to WhatsApp
- Live "Open now" badge based on Dhaka time (11 AM – 8 PM), reviews, map

Built by FutureStack Solutions. Photos are demo placeholders, to be replaced with the salon's own photos.
